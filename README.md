# VerbalOS

> **Your personal CAT VARC operating system.**

VerbalOS is a dedicated personal web application engineered for CAT VARC preparation.

## Features
- **Reading Comprehension Engine:** Original dense academic passages, WPM calibration, instant contextual word lookup, option elimination analysis.
- **Verbal Ability Master Center:** Para Summary with option trap categorization, interactive Para Jumbles with mandatory pair analysis, and Odd Sentence Out.
- **VARC Section Mocks:** Timed 40-minute simulated sectional tests with live Question Palette and +3 / -1 CAT scoring.
- **Mistake Journal:** Classifies cognitive errors (*Unsupported inference, Partial truth, Extreme option, Tone mismatch*) and prescribes tactical fixes.
- **Strategy & Selection Drills:** Passage triage and question difficulty prediction.
- **Cloud Synchronization:** Secure Google OAuth and Supabase PostgreSQL sync.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
